# 신카의 고리 — Monring Suika Game

> 넷마블 **신카의 고리** 캐릭터를 활용한 수박게임 스타일 팬 프로젝트입니다.

---

## 플레이 방법

1. `index.html` 을 브라우저에서 열기 (더블클릭으로 로컬 실행 가능)
2. 마우스를 좌우로 움직여 투하 위치 조준
3. 클릭하면 캐릭터가 낙하
4. 같은 캐릭터 두 개가 만나면 합쳐져 다음 단계로 진화
5. monring11 두 개가 합쳐지면 폭발하며 소멸 — 최고 점수를 노려보세요!

---

## 기술 스택

| 항목 | 내용 |
|---|---|
| 언어 | HTML5 + Vanilla JavaScript |
| 물리 엔진 | Matter.js 0.19.0 (로컬 파일, 오프라인 실행 가능) |
| 렌더링 | HTML5 Canvas 2D API |
| 사운드 | Web Audio API (외부 파일 없음) |
| 빌드 도구 | 없음 (순수 정적 파일) |

---

## 저작권 및 비영리 안내

본 프로젝트는 개인 학습 및 포트폴리오 목적으로 제작된 **비영리 팬 게임**입니다.
게임 내에 사용된 캐릭터 디자인 및 모든 이미지 리소스의 저작권은 **넷마블**에 있으며,
본 저장소는 어떠한 상업적 수익도 창출하지 않습니다.
권리자의 요청이 있을 경우 해당 리소스 및 게시물은 즉시 삭제하겠습니다.
